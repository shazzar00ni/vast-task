# vast-task
Productivity system for developers.

## Project tracking

Build work is tracked as GitHub issues, organized by the roadmap phases in the planning docs. See [`docs/github-issues-index.md`](docs/github-issues-index.md) for the full phase-by-phase index (app + landing page tracks).

## Working with AI coding agents

[`AGENTS.md`](AGENTS.md) documents this repo's status, phase/issue navigation, and the architecture decisions locked in during planning, for any AI coding agent working here. [`CLAUDE.md`](CLAUDE.md) points Claude Code at it directly. Update `AGENTS.md` when that guidance changes — `CLAUDE.md` just imports it, so there's one source of truth.
